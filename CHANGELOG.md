# Changelog

Tất cả thay đổi đáng chú ý của dự án sẽ được ghi nhận trong file này.

## [1.0.0] - 2025-01-01

### Thêm mới
- Bản đồ nền OpenStreetMap với Dark/Light mode
- 6 địa điểm tiêu biểu trên tuyến rước
- 5 chặng hành trình với hiệu ứng vẽ đường
- Hệ thống điều khiển hành trình (Bắt đầu / Tiếp tục / Quay lại / Toàn tuyến / Tự động)
- Bảng thông tin chi tiết địa điểm (Desktop sidebar + Mobile bottom sheet)
- Thanh tiến trình với dots tương tác
- Marker animations (bounce, pulse, scale)
- Polyline drawing animation
- Completion overlay với celebration effect
- Toast notifications
- Keyboard navigation (← → A V T F R Esc)
- Service Worker cho offline caching
- PWA manifest
- Responsive design (Mobile / Tablet / Desktop)
- ARIA accessibility labels
- Loading screen với progress bar
- MiniMap control
- Scale control
- Fullscreen toggle
- User location

### Ghi chú
- Tọa độ địa điểm là ước tính, cần cập nhật từ khảo sát thực địa
- Hình ảnh và audio chưa có, cần bổ sung
- Thông tin văn hóa cần được kiểm chứng bởi chuyên gia
